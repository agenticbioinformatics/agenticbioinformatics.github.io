Agentic Bioinformatics

Build into the new era of agentic bioinformatics! Here, revolutionary AI agents are improving the technology behind fast scientific prototyping. Agents are never asked what to do, but are told what to do.

Ideas from previous hackathons are turned into working software packages, while ensuring credits to authors and clarity about contributions. In addition, each project is accompanied by a prompt history file that documents the process, making it easy to trace back. The objective is to turn scientifically-sound prototype genomic workflows into reproducible, scalable and accessible tools with responsible tests, as well as to motivate others to build upon those projects.

Couple of rules:

  1. each project is accompanied by an open-source license (e.g. MIT, GNU)
  2. and includes an attribution to the authors, humans and agents, for example The scientific idea was introduced by [Author Name] at the hackathon [Hackathon Name] on May 9-10, 2026. The technology was created by agentic AI provided by Claude Sonnet 4.6. The original project is available under the [License] at [Link]
  3. always maintain a prompt history file with a summary of changes, you can create it using this prompt: Create or update a text file called "prompt_history" with my prompts and a summary of changes associated with each prompt
  4. agents are used for writing code, not for analyzing data (due to ethical and legal considerations)
  5. each project includes a README file for humans and agents
